## Summary of Changes
1. **Application & Personal Strategy language modules (`.mjs`)**:
   - Replaced all displayed Russian «фолд» / «перефолд» / «фолдить» strings with canonical «пас» / «перепас» / «спасовать» across `app/src/application/*-language.mjs`, `app/src/application/*-workspace.mjs`, and `app/src/personal-strategy/*.mjs`.
   - Preserved `перефолд` as an input-parsing alias in `app/src/personal-strategy/intent-interpretation.mjs` (`line 33`) while adding canonical `перепас` alongside it.
   - Replaced all displayed Hebrew «טווח» (where it refers to a poker hand range) with canonical «ריינג'» across all `.mjs` language/strategy modules.
   - Aligned Russian «Герой» → Latin «Hero» and Hebrew «השחקן» (when translating Hero) → «הירו».
   - Aligned Russian «вэлью» → «валью» and Hebrew poker value «ערך» → «ואליו» (while keeping ordinary showdown value «ערך בהצגה» in `exploit-teacher-language.mjs`).
   - Aligned Hebrew `studyCopy("open", "he")` from noun form `פתיחת מקור` to masculine imperative `פתח מקור`.
2. **Locale catalogs (`app/src/locales/*.js`)**:
   - Fixed shadowed legacy entries in `app/src/locales/i18n.js` (`"Clear": "Очистить"`, `"Fold": "Пас"`, `"FOLD": "ПАС"`, `"Hero": "Hero"`, `"Hero to act"` in RU/HE, HE `"Value": "ואליו"`, HE poker range `טווח` → `ריינג'`).
   - Replaced Russian «Герой» with «Hero» across `analysis-translations.js`, `home-translations.js`, `product-translations.js`, `guide-translations.js`, `welcome-translations.js`, `range-calibration-translations.js`, and `tutorial-translations.js`.
   - Converted all Hebrew `"Open …"` navigation/guide/action button labels from noun form (`פתיחת …`) to masculine imperative (`פתח …`).
   - Preserved Hebrew `טווח` where it denotes an ordinary numeric/configuration range (`i18n.js:1834` `בטווח הזה` for 2–10 players; `analysis-translations.js:126` `טווח הביטחון` for confidence interval).
