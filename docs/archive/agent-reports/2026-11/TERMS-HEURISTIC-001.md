# TERMS-HEURISTIC-001: "heuristic" is not user-facing wording

Ticket: TERMS-HEURISTIC-001 · Product Contract First (copy) · T1 · branch `wip/TERMS-HEURISTIC-001` (base `e884ce6`)
Decision: OWNER_DECISIONS 2026-10-31 ("Heuristic" is dropped from user-facing text). Training was done earlier (`logic.js` `trainingTerm`); this ticket covers every other surface.

## 1. Outcome

Analyze, Hand review, Review, Saved, Settings, Learn, Home, Personal Strategy, the tours and the tooltips now say **Baseline** with its tier ("Baseline · Estimated · Preflop") in EN; RU **«Базовая стратегия»**, HE **«אסטרטגיית בסיס»** (docs/TERMINOLOGY.md). 115 catalog strings changed (EN 38, RU 38, HE 39), plus the static English fallback text in `index.html`, two inline EN/RU/HE triples and two raw English messages. **No key, ID, contract or logic changed.** A Firefox scan of the whole DOM (visible text plus `title`, `aria-label`, `placeholder`, `alt`) in EN, RU and HE across Analyze (with a result showing), Range Category Comparison, Home, Hand, Equity, Training, Personal Strategy, Learn, Saved, Game night and the Settings dialog found exactly one occurrence: the hidden technical source id `riverline-preflop-heuristic/v4` (allowed, section 3).

## 2. How it was done (the design choice)

The catalog keys are the English strings, so changing the English text without changing a key needed care:

- **EN text:** the English catalog is generated as "key = key" for product keys, then merged by several files. The existing idiom in `app/src/locales/i18n.js` ("bounded copy edits retain the existing lookup keys") now has a second loop, `TERMS-HEURISTIC-001`, that sets the English display text for 31 keys. Seven more English entries were already explicit (`analysis-translations.js` `residualUi`) and were edited in place. The keys, and every `t('...')` call site, are untouched, so RU and HE keep resolving.
- **RU and HE:** values edited in place in `analysis-`, `guide-`, `home-`, `product-`, `tutorial-` and `range-calibration-translations.js` (a scripted, exact-text replacement of string values; keys never matched). A re-dump of the merged catalogs confirmed all 115 planned (language, key) values landed.
- **`app/index.html`:** only the static English fallback text and `aria-label`/`title` values; every `data-i18n*` key attribute is unchanged.
- **Inline code strings:** `study-language.mjs` (`heuristicBaseline` triple, Study Inbox label), `range-language-facts.mjs` (the name of the baseline in Personal Strategy narrative sentences), `strategy-provider.mjs` ("The baseline strategy is unavailable.") and `strategy/heuristic-strategy.mjs` (the unavailable explanation for a postflop facing-wager). The last two are displayed raw; the existing assertion in `strategy_repair001a_quality.test.mjs` matches only their prefix.

## 3. What was deliberately kept

Per the ticket (Explain's Source / provenance details, docs, code identifiers):

- The `analysis.*` catalog family in all three languages (Explain: "Heuristic estimate" provenance, the sampled-equity facts, the heuristic warnings) and the Explain fact label `Heuristic sampled equity`.
- The source-authority limitation messages (e.g. "Postflop position uses a bounded heuristic adjustment...", the "broad fallback" messages; RU has 9 entries, HE 3 that still say эвристика / היוריסטי).
- The technical source id `riverline-preflop-heuristic/v4` (hidden `technical-id` element).
- Code identifiers and IDs (`heuristic_comparison`, `heuristic_preflop`, `family === 'heuristic'`, `resolveHeuristicStrategy`, `heuristicBaseline` role key, file names), comments, docs, test titles.
- `StrategyResult.explanation` text produced in `strategy/heuristic-strategy.mjs` for available results ("The heuristic baseline prefers ..."): it is contract data, the UI shows the catalog keys `strategy.heuristic.*` instead (changed), so it is not user-visible. Left alone to keep the versioned result unchanged.

**Owner decision:** if you want the Explain provenance wording gone as well, the `analysis.*` family is about 30 more strings (and the RU/HE source-authority messages); say so and it is a mechanical follow-up.
