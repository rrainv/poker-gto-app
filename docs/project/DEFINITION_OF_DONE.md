# Definition of Done

A task is complete only when:

- scope matches the ticket
- no unrelated files changed without explanation
- canonical implementations remain canonical
- tests were run
- new behavior has tests where appropriate
- poker math preserves invariants
- UI behavior works in supported layouts
- translations are complete for new user-facing text
- model changes have schema/version metadata
- ONNX changes were validated against PyTorch where applicable
- the completion report lists files changed
- known limitations are documented

For experiments:

- configuration is reproducible
- seed is recorded
- output artifact is identified
- compute/time/spend is recorded
- success criteria were evaluated
