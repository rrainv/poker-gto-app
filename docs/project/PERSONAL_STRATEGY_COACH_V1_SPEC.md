## Concept dependencies

Each executable concept record separates a factual/reasoning question from stronger descriptive analysis, reference comparison and normative assessment. Dependencies explicitly name current Hand facts, Hero weighted range, opponent weighted range, opponent response policy, accepted reference, Equity when called, Range Evolution and normative authority.

| Concept | Reasoning question / stronger-analysis boundary |
|---|---|
| Value | Which worse hands call? Actual value targeting requires an explicit calling region and appropriate Equity/response evidence. |
| Thin value | Which weaker calls remain at this size? No automatic thin-value label from one pair. |
| When not to bet | What does betting gain over checking? No invented comparative EV. |
| Semibluff | What better hands fold while the draw can improve? Draw facts alone do not establish a role. |
| Bluff | Which better hands are targeted to fold? A proposed target is a premise, not a measured response. |
| Bluff catch | Which bluffs can reach this street? Reachable opposing policy/range evidence is required. |
| Blocker quality | Which response region is removed? Raw removal is not strategic quality. |
| Check-raise | What does Villain bet when checked to? Composition needs a supplied response policy. |
| Small/block bet | Which worse calls and raises are expected? Preserve exact amount semantics. |
| Polarization | Explain the definition; actual range shape needs an explicit strength criterion. |
| Value:bluff composition | Actual roles require compatible reachable response partitions; no automatic balance verdict. |
| Exploit | Conditional opponent assumptions remain explicit and versioned; no normative exploit claim without proper authority. |

Missing response, weighted Equity, accepted reference and range-level normative authorities remain first-class unavailable. Asking a useful concept question does not establish correctness.
