# UI Stabilization Prompt

Explorer mode first.

Do not modify poker logic, evaluator, equity, training, state schema, or models.

Audit:

- layout
- spacing
- typography
- colors
- components
- loading states
- empty states
- errors
- responsive layout
- dark/light theme
- accessibility
- translation overflow

Propose a small design system using existing application structure.

Do not rewrite the entire UI.

After approval, implement incrementally.

No new product features during the UI stabilization pass.
