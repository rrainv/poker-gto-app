# Personal Strategy question flow: design interview (owner, from 2026-10-19)

M2 feature. Builds on NORTH_STAR §7.1 (spot map home, grouped spots, Always/Sometimes/Never + optional %, unknown never fold, conflicts asked not auto-changed, plan statistics as bounds).

| # | Topic | Decision | Date |
|---|---|---|---|
| PS-01 | Answering for a group of hands | **Thresholds first** (drag cut-offs along an ordered hand family to set the shape fast) **+ brush for personal overrides** (people don't follow strict boundaries; paint exceptions freely) **+ table questions to firm up the boundaries** (the hands at each cut-off asked one at a time at a mini table, so the edges become clear and understandable for Riverline). **Buckets dropped.** The edge-family sweep's visual design gets reworked (new mockup). | 2026-10-19 |
| PS-02 | Three-action spots (3-bet / call / fold) | **B by default:** each hand gets a main action plus an optional "sometimes" second action (e.g. "call, sometimes 3-bet"); on the threshold strip a border can be widened into a **mixed band**; table questions offer 3-bet / call / fold / "a mix" (then: which two); the brush has a mix option. **C on request:** exact percentages per hand (or per band) whenever the user wants to enter them. Plan figures shown as ranges unless every contributing hand has a %. | 2026-10-19 |
| PS-03 | Hand categories | **Answer by families, teach with roles** (preview https://claude.ai/artifact/Cdx37aMzUUiPH8ZDKPGG1K). Families (ordered, stable) are the input for thresholds/brush/table questions; roles are Riverline's spot-specific reading of the answers (labelled, describing actions, never the person), feeding explanations and the style readout; role shortcuts later, once learned. Approved in principle; **several competing visual versions to be built and compared** before final. | 2026-10-19 |
| PS-04 | Sizes and stack depth | **C: one base plan per spot at the main depth, plus short "what changes here?" follow-ups** for other depths/size groups the user actually plays (from Table rules and recorded hands: owner = home game ~30–60 bb, online 9-max 100 bb+). Unchanged hands carry over, marked as carried over. Open sizes grouped small / standard / large. Own sizes (3-bet size IP/OOP etc.) asked once per spot type. B (full separate plans) is theoretically better but out of scope; the difference layer can be extended per context by users who want more detail. | 2026-10-19 |
| PS-05 | Pace of building the plan | **All three layers exist:** **Thorough setup** (answer many spots in one go; the owner's own preference), **Guided steps** (one spot ≈5 min, ending with "Drill these hands now" or "Keep building"; next spot chosen by how often it occurs in the user's real hands), and **Free picking** from the spot map. The user chooses (asked once at the start, changeable anytime); after any step they can continue building instead of training. Every answered spot is useful immediately (drill, baseline comparison, plan-vs-play notes). No % complete. | 2026-10-19 |
