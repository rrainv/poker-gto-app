| P1-03 | Choosing an action | **Select + confirm everywhere** by default (click an action, then confirm with the button carrying the amount). Setting to change it (Instant, Hold) in Settings › Training. Discoverability: after a few confirmed answers, a small one-time inline prompt like "Don't want to confirm? Never repeats once answered; quiet, non-modal. | 2026-10-18 |
| P1-04 | Decision controls | **Both** exist as shared components with the same rules (select + confirm, costs visible, sizes in one place, same colours): big action cards and round seat buttons. | P1-05 | Training panels | **All five**: spot at a glance (pot, price, equity needed, stacks); opponent's likely range (mini matrix, Estimated); this session's results by spot type; your plan + baseline after answering; similar spots you've played. **Everything reachable at any time or at most one click/expand away** (calm surface, deep data); more panels welcome later. No answer leaks before submission: plan/baseline content stays locked until the answer. Which panels are open by default is decided on the mockup. | 2026-10-18 |
| P1-06 | Motion tempo | **Frequency decides motion** (from the motion research): drill actions and anything keyboard-triggered are near-instant (0–120 ms, no growing bars on every answer); hover/select/press about 100 ms (press scale ~0.97); panels, dropdowns, feedback 150–250 ms; dialogs 200–300 ms; table moments (deal, chips) 250–300 ms, physical but never slow; rare moments (session end, milestones) may be longer and expressive. Strong ease-out for entrances, exits shorter, never ease-in for entrances; popovers grow from their trigger; animate transform/opacity only; reduced motion = short fade, not nothing. Encode these rules in a design/motion skill file that every agent loads. | 2026-10-18 |

Reference for P1-06: emilkowalski/skills (MIT), skill `emil-design-eng`: frequency table (100+/day no animation; tens/day drastically reduced; occasional standard; rare can delight), never animate keyboard actions, custom curves (ease-out cubic-bezier(.23,1,.32,1); ease-in-out cubic-bezier(.77,0,.175,1); drawer cubic-bezier(.32,.72,0,1)), never ease-in for UI, durations (press 100–160 ms, tooltips 125–200, dropdowns 150–250, modals 200–500; UI under 300), press scale .97, never from scale(0), origin-aware popovers, transitions over keyframes, blur bridge on crossfades, stagger 30–80 ms, exits faster, hover gated to fine pointers, reduced motion keeps fades. Plan: install the skill (or our adapted copy) for Claude Code workers on motion tickets.
